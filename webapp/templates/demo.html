What a tutoring exchange actually looks like

Illustrative, written to match the real profile above - this is what the AI writes using what `ask_tutor` returns. Notice it doesn't just answer the math question; it heads off the specific mistake pattern before it happens, and reaches for an analogy Alex actually cares about.

can u help me with this word problem - a team scores 3 points per goal and already has 14, how many more goals to reach 32?
Before we solve it - read it once more and underline what it's actually asking for. It says "how many MORE goals", not the total goals, so we need the gap first: 32 - 14 = 18 points still needed. Each goal is worth 3, so it's 18 / 3. Want to try that division, or think of it like a match: you're down 18 points and every goal closes 3 of them - how many goals to close the gap?

That "read it once more" line isn't generic good advice - it's there because the profile flags this exact habit (skipping re-reads, missing "total" vs "difference"-style wording) as a recurring pattern, not a one-off mistake.

And the exchange gets logged: if Alex gets the division right, `update_learning_progress` records it against this topic, so the trend (not just the latest attempt) is visible next session - and a session summary saves automatically when the conversation wraps up.
